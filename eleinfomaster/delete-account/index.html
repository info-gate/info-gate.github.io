엘리마스터 계정 삭제 요청

⚠️ 영구 삭제 — 복구 불가
시행일: 2026-06-01

방법 1 — 앱 안에서 직접 (권장)

  1. 엘리마스터 앱 실행 → 로그인
  2. 하단 탭 "설정" → "계정 삭제" 메뉴
  3. 비밀번호 재입력으로 본인 확인
  4. "영구 삭제" 버튼 → 즉시 처리

※ Sprint 2 에서 앱 내 삭제 메뉴 추가 예정. 현재는 아래 방법 2 로 부탁드립니다.

방법 2 — 이메일 요청

아래 이메일로 삭제 요청을 보내주시면 영업일 기준 3일 내 처리합니다.

계정 삭제 요청 메일 보내기

삭제 처리 절차

  1. 회원 정보 (이메일·이름·전화번호·비밀번호 해시) 즉시 삭제
  2. 비즈니스 데이터 (회사가 입력한 자산·점검·청구 등) — 회사 계정 모든 사용자 동의 시 영구 삭제
  3. audit_logs (전자상거래법 5년 보관 의무) — 익명화 후 보관 (이메일·이름 → 해시)
  4. 30일 보관 후 (오인 탈퇴 복구 기간) 백업에서도 영구 제거

주의 사항

  • 사장 (owner) 계정 삭제 시 → 회사 전체 데이터 삭제 (다른 사용자에게도 영향)
  • 기사/관리자 계정만 삭제 가능 (회사 데이터 유지) — 사장이 앱 설정 → 멤버 관리에서 처리
  • 현재 진행 중인 미수금/약속/점검은 다른 사용자에게 인계 후 삭제 권장
  • 월 구독 중인 경우 결제 취소 별도 필요
