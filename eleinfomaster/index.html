한 줄 정체성

한국 중소 승강기 유지관리 업체가 점검·신고·미수금·검사까지 폰 하나로 끝내는 가장 쉬운 도구.

세 가지 핵심 가치

  • 점검·신고·검사 — 자체점검 체크리스트 + 24시간 사고 신고 자동 추적 + 정기검사 flow
  • 미수금 회수 — 청구·입금 자동 매칭 + 약속 등록 시 약속일 자동 알림
  • 자산·영업 — 공공 API 자동완성으로 12개 필드 한 번에 + 검사 만료 임박 자동 영업 리드

데이터 안전

  • 멀티테넌트 격리 — 각 회사 데이터 완전 분리
  • 모든 청구·입금 거래 audit 로그 (분쟁 대비)
  • 민감 정보 (이메일·전화·금액) 로그 차단
  • JWT 인증 + bcrypt 비밀번호 해시
