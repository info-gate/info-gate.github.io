4. 제3자 제공 / 위탁

4.1 제3자 제공

이용자의 개인정보를 외부 제3자에게 제공하지 않습니다. 단, 다음 경우 예외:

  • 법률 또는 수사 기관의 적법한 요청
  • 이용자가 사전에 동의한 경우 (예: 카카오 알림톡 발송)

6. 보안 조치

  • 비밀번호 bcrypt 해시 (10 rounds)
  • JWT access (15분) + refresh (30일, SHA-256 해시 DB 저장, rotation)
  • HTTPS 전송 (Cloudflare Tunnel)
  • 멀티테넌트 격리 — 각 회사 데이터는 company_id 로 격리, cross-tenant 쿼리 차단
  • 모든 비즈니스 거래는 audit_logs 에 기록 (분쟁/사고 추적)
