엘리마스터 (EleInfoMaster) 이용약관

시행일: 2026-06-01

제1조 (목적)

본 약관은 주식회사 인포게이트 (이하 "회사") 가 제공하는 엘리마스터 서비스 (이하 "서비스") 의 이용 조건 및 절차, 회사와 이용자의 권리·의무·책임 사항을 규정합니다.

제2조 (용어 정의)

  1. "서비스" — 엘리마스터 모바일/웹 앱 및 관련 API.
  2. "이용자" — 본 약관에 동의하고 서비스를 이용하는 회원 (사장/관리자/기사).
  3. "회사 계정" — 한 회사 (유지관리 업체) 가 등록한 멀티테넌트 단위.

제3조 (서비스 내용)

회사는 다음 서비스를 제공합니다:

  • 승강기 자산·점검·검사 관리
  • 24시간 사고 신고 데이터 자동 준비 + 임박 알림 (실제 신고는 elevator.go.kr 에서 사용자 직접 진행)
  • 청구·입금·미수금 약속·연락 이력 관리
  • 공공 API 통합 자동완성 (한국 공공데이터포털)
  • 영업 리드 자동 발굴
  • 역할별 (사장/관리자/기사) 화면 분리

제4조 (회원 가입 및 자격)

  1. 한국 내 등록된 승강기 유지관리 업체 운영자 또는 그 직원만 가입 가능합니다.
  2. 가입 시 회사명·사장 이름·이메일·비밀번호 입력이 필수입니다.
  3. 회사 계정 당 첫 가입자는 자동으로 사장 (owner) 역할입니다.

제5조 (이용자 의무)

  1. 이용자는 정확한 정보를 입력해야 합니다.
  2. 법령·약관·운영정책에 따라 서비스를 이용합니다.
  3. 승강기 자체점검·정기검사·사고 신고의 법적 의무는 이용자 (업체) 본인에게 있습니다. 본 서비스는 데이터 준비 + 알림까지 보조하며, 실제 법적 신고는 외부 시스템에서 사용자가 직접 수행합니다.
  4. 타 회사 데이터 접근 시도, 서비스 무단 분석/리버스 엔지니어링, API 남용 금지.

제6조 (회사의 의무)

  1. 회사는 안정적인 서비스 제공을 위해 최선을 다합니다.
  2. 회사는 이용자의 개인정보를 「개인정보 처리방침」 에 따라 보호합니다.
  3. 점검·정기점검·시스템 업그레이드 시 사전 공지합니다 (긴급 보안 패치 제외).

제7조 (요금 및 결제)

  1. 1차 출시 베타 사용자는 1년 체험판 제공.
  2. 체험판 종료 후 월 구독 전환 시 30일 전 안내.
  3. 결제 정보·내역·환불은 별도 「결제 약관」 에 따릅니다.

제8조 (서비스 변경/중단)

  1. 회사는 운영상·기술상 필요 시 서비스 일부 또는 전체를 변경/중단할 수 있으며, 30일 전 사전 공지합니다.
  2. 천재지변·전쟁 등 불가항력 사유 시 즉시 중단 가능합니다.

제9조 (책임 제한)

  1. 회사는 이용자의 법적 의무 미이행 (자체점검 10일·사고 24시간 신고) 으로 인한 과태료·손해에 대해 책임지지 않습니다.
  2. 이용자가 입력한 데이터의 정확성 책임은 이용자에게 있습니다.
  3. 공공 API 응답 지연·오류로 인한 손해에 대해 회사는 책임지지 않습니다.
  4. 회사의 고의·중대한 과실로 인한 손해는 손해배상 범위 내에서 책임집니다.

제10조 (분쟁 해결)

본 약관에 관한 분쟁은 대한민국 법률에 따르며, 회사 소재지 관할 법원을 1심 법원으로 합니다.

제11조 (약관 변경)

회사는 약관을 변경할 수 있으며, 변경 시 시행 7일 전 (이용자 불리 변경은 30일 전) 공지합니다. 이용자는 변경에 동의하지 않을 권리가 있습니다.
