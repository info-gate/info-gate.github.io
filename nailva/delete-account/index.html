Account Deletion

Nailva — Nail Salon Manager (개발자: wowpia / Info-Gate Inc.) · 최종 업데이트: 2026-06-24
요약 / Summary
Nailva 는 기본적으로 모든 데이터를 사장님 기기 내부 (SQLite)에 저장합니다. 앱을 삭제하면 모든 데이터가 즉시 제거됩니다.
클라우드 백업(설정 → 클라우드 백업)을 사용한 적이 있다면, 서버 계정 삭제를 추가로 요청하셔야 합니다.

Nailva stores all data locally on your device (SQLite) by default. Uninstalling the app removes all data immediately. If you have used Cloud Backup, a separate server account deletion request is also required.

1. 삭제 방법 (How to Delete)

방법 1: 로컬 데이터만 사용한 경우 / Local Data Only

클라우드 백업 기능을 사용한 적이 없다면 기기에서 앱을 삭제하는 것만으로 모든 데이터가 영구 삭제됩니다.

If you have never used Cloud Backup, simply uninstalling the app permanently removes all data.

  1. Android: 설정 → 앱 → Nailva → 제거 / Settings → Apps → Nailva → Uninstall
  2. iOS: 홈 화면 → Nailva 아이콘 길게 누르기 → 앱 제거 / Long-press Nailva → Remove App

✅ 즉시 영구 삭제됩니다 (Instant permanent deletion).

방법 2: 클라우드 백업을 사용한 경우 / If You Used Cloud Backup

설정 → 클라우드 백업 메뉴에 로그인한 적이 있다면, 서버에 데이터가 백업되어 있을 수 있습니다. 서버 계정 삭제를 요청하세요:

If you have ever logged in via Settings → Cloud Backup, your data may be on our servers. Request server account deletion:

  • 수신 / To: wowpia0127@gmail.com
  • 제목 / Subject: [Nailva] Account Deletion Request
  • 본문에 포함할 정보 / Include in body:
    • 로그인 시 사용한 소셜 계정 유형 (Kakao / Google) / Social provider used
    • 가입 시 이메일 주소 / Email used at signup
    • 앱 내 닉네임 / Nickname in the app

✅ 요청 접수 후 7일 이내 처리됩니다. / Processed within 7 days of receipt.

처리 완료 시 동일 이메일로 회신드립니다. / We will reply to the same email when complete.

방법 3: 데이터 일부 삭제 (계정 유지) / Partial Data Deletion (Keep Account)

계정을 유지하면서 일부 데이터만 삭제하고 싶을 때는 앱 내에서 직접 진행하세요:

To delete some data while keeping your account, do so directly in the app:

  • 고객 1명 삭제 / Delete one customer: 고객 목록 → 해당 고객 → 우측 상단 ⋯ → 삭제
  • 시술 기록 1건 삭제 / Delete one service record: 고객 상세 → 시술 기록 → 항목 길게 누름 → 삭제
  • 사진 1장 삭제 / Delete one photo: 시술 상세 → 사진 탭 → 사진 길게 누름 → 삭제
  • 예약 1건 삭제 / Delete one booking: 캘린더 → 예약 → 삭제
  • 전체 고객 데이터 초기화 / Wipe all customer data: 설정 → 데이터 관리 → 초기화
  • 클라우드 백업만 중단 / Stop cloud backup only: 설정 → 클라우드 백업 → 로그아웃 (로컬 데이터는 유지)

✅ 모든 부분 삭제는 즉시 영구 적용됩니다. / All partial deletions are instant and permanent.

익명화된 통계 / Anonymized Aggregate Statistics

서비스 개선을 위한 익명화된 집계 통계(예: 일일 활성 사용자 수, 기능 사용 빈도 등)는 보관될 수 있습니다. 개인을 식별할 수 없는 형태로만 유지됩니다.

Anonymized aggregate statistics may be retained in non-identifiable form for service improvement.

제3자 서비스 / Third-Party Services

  • Google AdMob: 광고 ID 는 Google 정책에 따라 별도 관리됩니다. 기기 설정 → 개인정보 → 광고에서 광고 ID 재설정 가능. / Ad ID is managed by Google per their policy. Reset via device Settings → Privacy → Ads.
  • Firebase Analytics / Crashlytics: 익명 분석·크래시 로그는 Google 정책에 따라 자동 만료됩니다. / Anonymous analytics and crash logs auto-expire per Google's policy.
  • PostHog: 익명 사용 분석 데이터는 7일 후 자동 파기됩니다. / Anonymous usage analytics auto-expire after 7 days.
  • Sentry: 크래시 로그는 90일 후 자동 파기됩니다. / Crash logs auto-expire after 90 days.

4. 자주 묻는 질문 / FAQ

Q. 클라우드 백업을 사용한 적이 있는지 모르겠어요.

A. 앱 → 설정 → 클라우드 백업 메뉴에서 "로그인됨" 상태로 표시되면 사용 중입니다. 사용한 적이 없다면 앱 삭제만으로 모든 데이터가 제거됩니다.

Open Settings → Cloud Backup. If it shows "Signed in", you have used it. If not, uninstalling the app removes all data.

Q. 삭제 후 같은 소셜 계정으로 다시 가입 가능한가요?

A. 네, 가능합니다. 단, 이전에 백업된 고객·시술 데이터는 복구되지 않습니다.

Yes, you can sign up again, but previously backed-up data will not be restored.

Q. 일부 고객 정보만 삭제할 수 있나요?

A. 앱 내에서 개별 고객·시술 기록·사진을 직접 삭제할 수 있습니다. 전체 계정 삭제 없이 데이터 일부만 삭제하려면 앱 내에서 직접 진행하세요.

Individual customer records, services, and photos can be deleted in-app without removing the whole account.

Q. 처리 기간은 얼마나 걸리나요?

A. 앱 삭제는 즉시. 이메일을 통한 서버 계정 삭제는 접수 후 7일 이내 처리됩니다.

App uninstall is immediate. Server account deletion via email is processed within 7 days.
