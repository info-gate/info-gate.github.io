wowpia(이하 "회사")는 Barolingo 애플리케이션(이하 "서비스") 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」을 비롯한 관련 법령을 준수합니다. 본 방침은 이용자가 어떤 정보를 제공하고 어떻게 보호되는지 안내합니다.

1. 수집하는 개인정보 항목

1-1. 회원가입 시 (필수)

  • 소셜 로그인 식별자: kakao_id / google_sub / apple_sub
  • 이메일 주소
  • 닉네임 (소셜 계정 제공 값)
  • 프로필 이미지 URL (소셜 계정 제공 시)

1-2. 서비스 이용 중 자동 수집

  • 학습 기록: 세션 시작/완료, 청크 반응속도(ms), 정답률, 획득 XP, 스트릭
  • 디바이스 정보: OS 종류/버전, 앱 버전, 기기 모델, 언어 설정, 시간대
  • 이벤트 분석 데이터: 화면 이동, 로그인 성공, 학습 시작/완료 등 (PostHog)
  • 크래시 로그: 앱 오류 발생 시 스택 트레이스 (Sentry, 활성 시)
  • 광고 식별자: Google Advertising ID (AdMob — Free 플랜 유저의 광고 표시를 위해)
  • 푸시 알림 토큰: Expo Push Token (매일 K-단어 알림 발송용, 단말 식별 불가)
  • 알림 언어 설정: 사용자 선호 언어 (ko/en/ja, 알림 메시지 다국어 발송용)

1-3. AI 자동 생성 콘텐츠 안내

본 서비스의 "오늘의 K-챌린지" 단어 일부는 Google Gemini 인공지능이 매일 자동 생성합니다. 이 과정에서 사용자 개인정보는 외부 AI 모델로 전송되지 않으며, 단어 생성 prompt 만 사용됩니다. AI 생성 콘텐츠는 회사가 사전 검토 후 게시하며, 부적절한 콘텐츠 발견 시 즉시 제거합니다.

1-4. 친구 시스템 (Friends)

  • 친구 관계: 본인이 보낸/받은 친구 요청, 친구 ID 목록, 요청 상태(pending/accepted/rejected)
  • 친구 검색 입력: 검색 시 입력한 닉네임/이메일 (검색 결과 표시 후 저장하지 않음)
  • 응원 메시지 (User-Generated Content): 친구에게 보낸 응원 이모지 (👏🎉💪🔥⭐) + 짧은 텍스트 메시지
  • 친구 활동 알림: 친구 요청/수락/응원 수신 시 푸시 알림 발송 (위 1-2 의 푸시 토큰 사용)

응원 메시지는 발신자·수신자 본인만 볼 수 있으며 공개 게시판에 노출되지 않습니다. 부적절한 콘텐츠 신고 시 회사는 즉시 검토하여 삭제할 수 있습니다. 사용자가 친구 관계를 해제하거나 회원 탈퇴 시 관련 데이터는 즉시 파기됩니다.

Barolingo Privacy Policy

Last updated: May 17, 2026 · Effective: May 17, 2026

wowpia ("we", "us", "our") values the privacy of Barolingo users. This policy explains what information we collect and how we protect it, in compliance with applicable data protection laws.

1. Information We Collect

1-1. On Signup (Required)

  • Social login identifier: kakao_id / google_sub / apple_sub
  • Email address
  • Nickname (provided by social account)
  • Profile image URL (if provided)

1-2. Automatically Collected During Use

  • Learning data: session start/complete, chunk reaction time (ms), accuracy, earned XP, streak
  • Device info: OS, app version, device model, language, timezone
  • Event analytics: screen views, login success, session events (via PostHog)
  • Crash logs: stack traces on error (via Sentry, when enabled)
  • Advertising ID: Google Advertising ID (for Free-tier ad serving via AdMob)
  • Push notification token: Expo Push Token (for daily K-word notifications, no device identification)
  • Notification language preference: ko/en/ja (for multilingual delivery)

1-3. AI-Generated Content Notice

Some "Daily K-Challenge" words are auto-generated daily by Google Gemini AI. No user personal information is sent to the AI model — only generation prompts. AI-generated content is reviewed before publication, and inappropriate content is removed immediately upon discovery.

1-4. Friends System

  • Friend relationships: friend requests sent/received, friend ID list, request status (pending/accepted/rejected)
  • Search input: nickname/email entered when searching for friends (used for query only, not stored)
  • Cheer messages (User-Generated Content): emoji cheers (👏🎉💪🔥⭐) and short text sent to friends
  • Friend activity notifications: push notifications sent on friend request/accept/cheer receipt (uses the push token from section 1-2)

Cheer messages are visible only to the sender and recipient — never posted publicly. Reported inappropriate content is reviewed and removed promptly. When a user unfriends or deletes their account, related data is immediately purged.

2. Purposes of Collection and Use

  • Member identification and session persistence
  • Storing learning progress and calculating level/ranking
  • Personalized content recommendations
  • Service quality improvement and error diagnosis
  • Ad serving (Free tier) and monetization
  • Legal compliance and dispute resolution
